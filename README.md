# Fashion Retail Sales Analysis (2018–2022)

A group project analyzing fashion retail sales from 2018 to 2022 using Tableau.

## Project Overview

The dashboard explores seasonal sales composition, yearly blouse sales trends, and comparisons between average product prices and stockout frequency.

## Dashboard

Explore the interactive dashboard on Tableau Public:

https://public.tableau.com/app/profile/pe.gun/viz/Sales-Group12/SeasonalSalesPricingDiagnostics?publish=yes

## Key Findings

- Spring and Winter show relatively high sales volumes.
- Blouse sales vary across years and seasons.
- Jeans has the highest reported average stockout frequency, while Blouse has the highest average price.
